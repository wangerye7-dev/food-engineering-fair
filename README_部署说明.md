# 食品产业体验门户 V3 展会版

## 上传部署

1. 解压本压缩包。
2. 将解压后看到的全部文件和 `assets` 文件夹上传到 GitHub 仓库根目录。
3. 同名文件直接覆盖，新文件直接添加。
4. 提交到 `main` 分支，等待 GitHub Pages 发布完成。

## 主要页面

- `index.html`：沉浸式封面与APP式门户首页
- `challenge.html`：专业协同10题100分随机体验
- `majors.html`：专业协同与岗位介绍
- `survey.html`：企业人才需求与合作交流
- `cooperation.html`：校企合作需求登记
- `privacy.html`：信息收集与使用说明
- `admin.html`：当前设备数据查看与CSV导出

## 体验规则

- 食品智能加工技术：4题，共40分
- 食品质量与安全：4题，共40分
- 专业协同决策：2题，共20分
- 每题10分，总分100分
- 每次按能力维度随机抽题，并优先避开上一轮题目

## 重要说明

当前静态版本的表单记录保存在填写设备的浏览器中。正式多设备统一汇总时，需要接入学校批准的数据接口或表单服务。
