# 食品工程学院农洽会互动平台 V1（测试部署版）

## 已完成页面

1. `index.html`：统一首页与身份分流入口
2. `challenge.html`：食品工厂双线挑战（3关可运行）
3. `survey.html`：企业人才需求调研（完整12题）
4. `survey-success.html`：问卷提交回执页
5. `majors.html`：双专业介绍
6. `cooperation.html`：校企合作需求登记
7. `admin.html`：本机数据统计与CSV导出
8. `privacy.html`：信息使用说明测试稿

## 本地预览

不要直接双击网页文件测试全部功能。请在本目录打开终端运行：

```bash
python -m http.server 8080
```

浏览器访问：`http://localhost:8080`

## 可部署环境

本版本为纯静态网页，可上传至学校网站子目录、Nginx/Apache静态目录、GitHub Pages、Cloudflare Pages、Vercel 或其他静态托管平台。

## 重要限制

当前企业问卷、互动结果和合作登记使用浏览器 `localStorage` 存储：

- 不同手机或电脑的数据不会自动汇总；
- 清理浏览器数据后记录可能丢失；
- `admin.html` 只能查看当前设备产生的数据；
- 不适合作为展会正式多设备采集方案。

正式上线前必须接入学校批准的服务器或云数据库，并增加：

- 后端提交接口；
- 管理员身份认证；
- 数据访问权限；
- HTTPS；
- 数据备份与导出；
- 隐私说明、保存期限和删除更正渠道；
- 反重复提交和基础安全校验。

## 下一步部署信息

正式部署需要确定：

1. 测试域名或学校网站目录；
2. 后端环境（学校服务器、轻量云服务器或数据库服务）；

5. 展板二维码最终指向的网址。
